# 产品设计优化实施状态

更新日期：2026-09-08。对应 `product-design-optimization.md`；本文件记录实际实现，不替代目标方案。本次只修改前端仓库，整版方案尚未全部交付。

## 已实现的前端改造

- 本轮流程优化：任务/组件编辑接入公共离开保护，新建模板纳入未保存检测；关闭、页面导航和刷新共用脏状态。模板切换章节不再反复弹提示。
- 模板编辑显示集中待完善项与章节标记，点击进入对应章节并聚焦首个配置控件；保存明确作用于整份配置。已发布或有关联任务时保存需确认影响，发布前确认关联范围；失败就地保留错误，发布成功保留当前章节。
- 管理员首页列出具体缺失模板、缺失/停用目标和最近连接检测失败事项；任务直达详情，组件带入名称筛选。这里仅检查已加载的数据，不代表全部配置校验通过。
- 批量操作仅在选择任务后出现；表头支持选择当前页，提供取消选择入口。
- 补跑窗口按选择时间、核对业务时间、确认发送组织；目标技术信息可展开，缺失/停用目标阻止确认，并区分管理员与操作员的处理提示。

- 列表视觉复核：五个列表统一使用公共筛选栏与底部分页；筛选紧凑左对齐，搜索和状态控件同高，每页条数不再出现在表格上方。消息云组件、数据项列表已用独立示例进行浏览器检查，并验证条数切换写入地址。

- 按角色组织导航：首页、运行管理、配置管理；操作员无配置写入口，任务只提供历史补跑，管理员保留当前时间执行。
- 任务详情、执行详情、模板新建及编辑具有独立页面地址；公共详情页提供返回入口、标题焦点和固定底部操作区。
- 任务、模板、数据项、组件列表保留查询和分页参数；执行记录查询参数也写入地址。详情返回恢复列表条件，列表按钮导航记录滚动位置。
- 任务增加搜索、状态过滤、每页条数和当前页批量启停；批量请求逐项显示成功或失败，失败项保留选择。
- 任务与组件保存失败保留表单；创建模板失败显示表单错误；保存成功但刷新失败提示“已保存，部分列表更新失败”。模板新建不再隐式选择首个消息云组件。
- 数据分组独立加载，部分接口失败不阻断其他页面；保留旧数据并显示更新时间。执行查询、执行明细、时间预览及目录查询使用请求序号避免较早响应覆盖最新请求。
- 手工执行展示模板及消息云目标，缺少目标或目标停用时阻止提交；时间变化使旧预览失效；超时或服务端异常显示“结果暂未确认”，提醒先核查执行记录。
- 消息云连接检查记录真实结果及检测时间；修改组件后清除旧检查结果。不将数据加载成功等同于服务健康。
- 执行证据链不随明细筛选变化，部分成功或缺失阶段不显示为全链路完成。
- 模板编辑保留未保存提醒；“查看原文”明确区分于真实生成预览。模板页说明现有接口尚不支持发布版本隔离。
- 登录提示、页面名称及删除文案采用业务用语；删除确认优先聚焦取消操作。

## 未完成的前端与联调工作

- 模板编辑已有基础校验摘要、章节定位和影响确认；保存已发布模板时由后端保留最近发布快照，任务在新草稿发布前继续使用旧版本。完整工作台布局和所有错误的精确字段定位仍待完善。
- 主要新建/编辑表单已加入未保存保护；全量焦点返回、浏览器历史滚动、详情/抽屉/小型确认框的一致性及窄屏交互仍需继续验收。
- 历史补跑由后端按 Asia/Shanghai 解析，并依据服务端当前时间拒绝未来时间。
- 连接检测反馈已可见，但执行预检与管理员异常确认闭环尚未完成。
- 发布前完整性校验、草稿允许不完整和发布快照隔离已经落地；执行明细记录实际使用的发布版本。完整历史版本浏览和并发保存冲突提示仍待后续增强。
- 总览异常筛选、时间窗口透传与完整统计范围尚未闭环；当前页统计不可当作全量运行健康结论。
